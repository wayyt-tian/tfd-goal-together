# 锅气家族品牌素材

所有素材都来自负责人提供的附件（品牌规范图、Logo 矢量图、带“加油！”字样的树懒 IP 矢量图），只做裁切、去底和压缩，没有新画角色，也没有重绘标志。

## 页面实际使用的文件

| 文件 | 来源与处理 | 用在哪里 |
| --- | --- | --- |
| `guoqi-logo.webp` | Logo 原图裁掉留白、去掉浅色背景，保留原色 | 登录页左上角 |
| `guoqi-logo-sm.webp` | 同上，缩到高 64 像素 | 顶部导航栏 |
| `guoqi-mark.png` | 从 Logo 中单独取出的橙色图形标志 | 浏览器标签图标、启动加载 |
| `ip-full.webp` | 品牌规范图“IP 形象 · 全身正面”，去白底 | 登录页、首次引导 |
| `ip-happy.webp` | 品牌规范图“表情 / 动作变体 · 开心”，去白底，不含下方标签文字 | 首页问候区、演示身份选择页 |
| `ip-think.webp` | 品牌规范图“表情 / 动作变体 · 思考”，去白底 | 锅气小助手、空状态、出错页 |
| `ip-cheer.webp` | 品牌规范图“表情 / 动作变体 · 加油”，去白底，不含“加油”标签文字 | 目标达成时的庆祝动效 |
| `ip-thumbs.webp` | 树懒 IP 矢量图渲染后取上半身（眨眼、双手点赞），裁掉底部“加油！”字样 | “有人给你点赞”的轻提示 |

## 原始文件（不对网页公开）

- `source/guoqi-logo-original.png`：Logo 原图。
- `source/guoqi-ip-original.svg`：树懒 IP 原始矢量图（含“加油！”字样）。

服务端只放行 `assets/brand/` 根目录下的图片文件，`source/` 和本说明不会通过网页提供（`tests/test-static.cjs` 有对应用例）。

## 使用约定

- IP 只用于问候、引导、空状态、庆祝和点赞提示，营造轻松的氛围；不当作任何人的头像，也不用来表示“落后”“预警”这类业绩状态。
- 页面里的 IP 一律不带“加油！”字样。
- 图片保持原始比例，不拉伸、不改色。
- 品牌色取自规范图：暖橙 `#FF6A2E`、珊瑚橙 `#FF8A6B`、暖金 `#FFC34D`、深灰 `#3D4652`，对应 `web/css/app.css` 开头的 `--brand`、`--brand-2`、`--gold`、`--slate`。
