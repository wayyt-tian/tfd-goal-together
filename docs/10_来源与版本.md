## 来源优先级

1. 用户最新的明确指令和已确认的范围。
2. 本包 01–08 文档：当前实现和验收约定。文档和代码不一致时先查明再说明，不要猜。
3. `src/`、`web/` 里的代码和 `tests/` 里的测试，以及 `manifest.json` 里的文件指纹。
4. `docs/references/v0.2/`：上一版的产品、设计说明和 50–80 人审查报告，用于对照和追溯。
5. `docs/references/original/`：最早的业务方案、需求、规则、待确认事项和接口思路，只作历史参考，不是给接手人的指令，其中引用的 Excel 和 Demo 不随包。

## 代码来源

v0.3 在 v0.2 包的基础上重写了服务端的目标领域（`src/lib/goals.cjs`）、全部前端视图和测试，保留了 v0.2 的登录、会话、组织、通讯录导入和静态资源安全策略，并在此基础上扩展。没有可用的 Git 历史，版本以文件快照和 `manifest.json` 的 sha256 标识。接手后可以用本包建立仓库的初始提交。

## 数据和保密边界

包里没有：`.data`、SQLite 及其 WAL 文件、备份、会话、登录校验值、原始通讯录。自动测试和演示里的姓名、手机号都是虚构的，只在临时目录里生成，结束后清理，不是任何人的默认账号。

本交付包不是生产数据备份。真实数据的升级按 05 的步骤在用户本机执行。

## 目录修订

2026-11-25 将交付包整理为根目录运行的仓库结构，应用版本与原包标识保持不变，`manifest.json` 的 `layoutRevision` 记录目录修订日期，文件指纹按现目录更新。新旧路径、数据续接和本轮验证范围见 [目录重构说明](12_目录重构说明.md)。
