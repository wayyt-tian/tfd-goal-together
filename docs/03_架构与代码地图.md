# 架构与代码地图

当前版本使用 React 19、Vite 7、Node.js 和 PostgreSQL 16，源码采用 JavaScript / JSX。服务端通过内置 HTTP 提供同源接口、构建后的前端、品牌素材与字体。

```text
React 页面 → 接口客户端 → Node.js HTTP → PostgreSQL 连接池
               ↑                ↓
             增量同步 ← 服务器推送 ← 提交后的事件游标
```

| 位置 | 职责 |
| --- | --- |
| `src/server.cjs` | 正式/演示分流、启动与停止 |
| `src/application.cjs` | 独立模式实例：登录、路由、事务、静态文件和实时连接 |
| `src/lib/management.cjs`、`accounts.cjs`、`permissions.cjs`、`directory.cjs` | 管理接口、账号、能力授权与通讯录导入 |
| `src/db/index.cjs` | 连接池、异步查询、请求上下文、隔离空间、初始化、事务及数据库通知 |
| `src/db/migrations/001-initial.sql` | PostgreSQL 表、索引和事务游标函数 |
| `src/db/backup.cjs` | PostgreSQL 16 自定义格式备份工具 |
| `src/lib/goals.cjs` | 权限、目标树、汇总、事件、归档、交接和领域读模型 |
| `src/lib/demo.cjs` | 63 位虚构成员、4 个演示身份及虚构目标和进展 |
| `web/js/main.jsx` | 外壳、导航、路由、页面生命周期和实时提醒；详情等视图按需加载 |
| `web/js/react-runtime.jsx` | React 元素协调、输入保留、局部刷新及弹层 portal |
| `web/js/views/*.jsx` | 原有页面和展示组件，直接返回 JSX |
| `web/js/forms.jsx`、`ui.jsx` | 操作单、选人选目标、确认、提示和数字格式 |
| `web/js/store.js` | 已授权的数据、增量合并、目标父子索引和订阅 |
| `web/js/api.js` | 同源请求、登录校验码与服务器推送重连 |
| `vite.config.mjs` | 开发代理、React 编译、按需分包 |

服务端读取使用可重复读事务，组织数据批量加载，权限判断和树遍历在内存完成。写请求在同一连接的事务内完成业务变化、事件和游标；提交后才发送响应与广播。组织操作独占组织锁，普通写操作共享组织锁并按目标树加锁，随后锁定事务游标行，使一个写入批次的读模型不会混入另一批提交。写入批次仍按游标串行；本轮没有实现多写入节点吞吐扩展。

事件游标使用事务中的普通行计数器；撤回事务也撤回游标，不使用可能跨提交跳号的独立序列作同步水位。目标编辑保留版本号校验与 409。进展只追加、可撤回，归档保留整棵子树和历史。

读模型按提交游标和业务日期缓存。普通进展变化只重新读取受影响目标及祖先的汇总和自评；结构、组织、权限、规则和日期变化触发完整重建。失败事务的模型不发布。动态查询在 SQL 中完成授权过滤、游标分页和数量限制。

前端直接渲染 JSX，不在运行时解析旧 HTML 模板。React 按 `data-key` 对应的稳定键协调元素，表单控件保留本地编辑值；弹层通过 portal 管理，表单的局部原生事件绑定随对应 DOM 卸载。业务操作绑定到 React 元素，不使用 document 级业务事件委托。列表保留原来的搜索、分页、折叠和响应式断点。在线人数变化只更新顶栏；目标增量只重建受影响父目标的子项索引。

构建结果位于 `web/dist/`，服务端不提供前端源码。带内容指纹的 `/static/` 文件长期缓存，入口页面需重新校验；支持 ETag、压缩和内存压缩缓存。服务器推送不经过静态压缩流程。凭据派生使用异步 scrypt，避免阻塞事件循环。

数据库通知负责提交后的失效和唤醒，20 秒心跳提供补偿。登录失败锁定和限流仍在应用进程内，因此正式使用仍建议单个应用进程；多实例的完整安全策略不在本轮范围内。

正式实例和演示实例分别持有连接池、会话、缓存和实时订阅，接口前缀与 Cookie 路径独立；详见 [v0.4 正式模式](14_正式模式与账号管理.md)。
