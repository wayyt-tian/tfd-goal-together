# 目录重构说明

> 本文记录此前交付或目录整理阶段。当前 PostgreSQL 与 React 实现、启动方式及验证以 [本轮重构说明](13_PostgreSQL与React重构.md) 和第 03–06 份文档为准。

整理日期：2026-11-25。应用版本保持 0.3.0。本轮将研发交付包整理成可以持续开发的仓库目录，统一从根目录运行命令。

## 目录职责与新旧路径

| 原路径 | 当前路径 | 职责 |
| --- | --- | --- |
| `app/package.json` | `package.json` | 根目录命令入口 |
| `app/server.cjs` | `src/server.cjs` | 服务启动、接口与静态资源白名单 |
| `app/lib/` | `src/lib/` | 目标领域、历史迁移、演示数据 |
| 分散的资源路径常量 | `src/paths.cjs` | 服务端和导入脚本共用的目录定位 |
| `app/web/` | `web/` | 前端原生模块和页面样式 |
| `app/assets/brand/` | `assets/brand/` | 原有 Logo、IP 及原始素材 |
| `app/fonts/` | `assets/fonts/` | 字体与字体许可证 |
| `app/LICENSE-lucide.txt` | `assets/licenses/LICENSE-lucide.txt` | 图标许可证 |
| `app/scripts/test-*.cjs` | `tests/test-*.cjs` | 测试入口、测试用例与公共工具 |
| `app/scripts/` 中的其他脚本 | `scripts/` | 演示启动与通讯录导入 |
| 根目录 `00`–`11` 文档 | `docs/` | 产品、业务、架构、交接说明 |
| `app/README.md`、`PRODUCT.md`、`DESIGN.md` | `docs/开发指南.md`、`产品说明.md`、`设计说明.md` | 开发、产品和设计说明 |
| `data/` | `docs/examples/` | 表结构及接口样本，不是运行数据 |
| `screenshots/` | `docs/screenshots/` | 原演示截图 |
| `references/` | `docs/references/` | 原始方案与上一版文档，内容原样保留 |
| `validation/` | `docs/validation/original-v0.3/` | 原交付的验证输出，内容原样保留 |
| 原根目录 `README.md` | `README.md` | 重写为当前仓库的运行和文档入口 |

根目录保留 `AGENTS.md`、`package.json`、`manifest.json` 和 macOS 演示启动器。旧 `app/.gitignore` 的规则合并到根目录 `.gitignore`。品牌图片、字体、第三方许可证、前端文件、目标领域及迁移数据未改动内容；素材和样例的说明文档同步修正路径。旧目录无需兼容软链接。

## 运行和数据

在根目录执行 `npm test`、`npm run demo`、`npm run demo:live` 和 `npm start`。直接运行服务的入口改为 `node src/server.cjs`；测试入口改为 `node tests/test-all.cjs`。`启动演示.command` 同步调整到根目录。

资源目录统一以仓库位置解析，不依赖启动进程所在目录。字体在磁盘上移到 `assets/fonts/`，浏览器仍通过 `/fonts/dm-sans-latin.woff2` 访问；页面、脚本和品牌资源的浏览器地址保持一致。服务端源码、文档、测试、工具、品牌原始文件与许可证不对外提供。

默认数据目录从 `app/.data/` 调整为根目录 `.data/`。已有部署通过 `GUOQI_DATA_DIR` 指向原目录继续使用。本轮没有连接或搬迁正式数据库；续接步骤见 [本地运行与数据续接](05_本地开发与数据续接.md)。原有环境变量名称和业务接口保持一致。

## 清单与历史资料

修改完成后，依次执行：

```sh
npm run package:manifest
npm run package:check
```

生成器保留应用版本和原始包来源，增加目录修订日期，更新文件大小及 SHA-256。根目录 `.git` 元数据不计入交付清单；数据库、运行数据、依赖和缓存仍会被拒绝。原交付报告的指纹与路径只描述历史快照；当前清单在根目录 `manifest.json`。

`docs/references/` 和 `docs/validation/original-v0.3/` 是历史存档，其中提到的旧路径不作为当前启动指令。原历史方案中未随包提供的附件链接仍按历史边界保留。
