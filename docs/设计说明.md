# 锅气家族 · 目标共创台：设计说明

设计变量、动效清单和品牌使用规则见同目录《08 设计与品牌规范》；本文讲每个页面怎么排、为什么这样排。

## 总体

暖白底（`#FFF8F1`）+ 白色卡片 + 品牌暖橙点缀，大圆角，柔和阴影。顶栏放 Logo、“目标共创台”字样、页面导航、实时呼吸灯和“新建”按钮；手机上导航移到底部，右下角是圆形“+”。页面内容最宽约 1180px，居中。

层级靠留白和字号，不靠线框和表格。数字大、单位小；每个状态都带文字。

## 我的（首页）

1. **问候区**：IP（开心）轻轻漂浮；标题根据情况变化，例如“今天有 3 件事值得看一眼”“今天节奏不错”“新周期就要开跑了”；下方一行总结和相关公司目标的小标签；底部“刚刚”滚动快讯。
2. **提示条**（有才出现）：你不在的时候发生了什么、有待交接的目标（仅公司负责人）、谁给你点了赞。
3. **新手引导**（只出现一次）：三步说明 + “试着记第一笔”“新建一个”。
4. **三组卡片**：我负责的（按需要关注的程度排序）、我参与的、我的自主目标。卡片顶上是所属公司目标的路径，中间是标题和数字，右侧是进度环和状态，底部是“记一笔”。
5. **团队速览 + 锅气小助手**：只对有团队的人显示。
6. **空状态**：IP（思考）+ “先找到你的第一个目标”+ 去目标地图的按钮。

## 目标地图

页头一句说明和“本期时间已过 xx%”，下面是“刚刚”快讯。最上层只放公司目标的大卡片（北极星），每张显示进度环、负责人和周期、数字、带时间刻度的进度条、状态标签（例如“2 需要支持”“3 项落后”）和“几项 · 几人”；公司负责人多一张虚线的“添加公司目标”卡。下面左边是“现在最需要关注”（落后、需要支持或很久没更新的末端目标，每条带负责人和路径，最多 6 条，其余提示去目标页看），右边是锅气小助手；最后是“大家发起的自主目标”，默认展示一部分，可展开全部。点任何一张卡片进入目标页继续下探。

## 目标页

**头部**：路径面包屑（从公司目标到当前）、标题、负责人和协作者、大号数字（现在 / 目标 + 单位；“做完就行”显示“几 / 几项完成”）、进度环、一句节奏说明（时间过去多少、比时间进度快或慢几个点、还差多少；达成后写“已经达成，超出多少”）、三个小事实（几条路径、几人参与、最近进展是哪天）。操作按钮按权限出现：记一笔、加入协作、往下拆、说一句，其余（编辑、完成、归档等）收在“更多”里。

**三个页签**：

- **拆解路径**：可切换“下一层 / 全部层级”，并按 全部 / 需要关注 / 已达成 筛选。每一行显示负责人头像、标题、状态、下层概况（几项、几项落后、几处需要支持、占上级多少）、数字和带时间刻度的进度条；有下层的可以继续点进去。下方单列“挂靠在这里的自主目标”，注明不计入上面的数字。
- **成员**：这个目标下的所有人，按需要关注的程度排序。
- **动态**：这个目标的全部变化，可以留言、点赞，记录人本人可以撤回。

没有下一层的目标默认打开“动态”页签。

## 团队

页头一句话：“14 位同事（3 位直属），关联 21 个目标。按‘需要关注’的程度排在前面。”下面四张统计卡：都顺利 / 有落后 / 需要支持 / 很久没更新的人数；再下面是筛选（全部 / 需要关注 / 需要支持 / 很久没更新 / 都顺利）和搜索（姓名、职位、部门）。名单按部门分组、可折叠，组标题上写着这一组有几人需要关注；每人一行：头像、姓名职位、每个目标一个状态色点和“负责几 · 参与几”、最需要关注的一个状态、最近更新时间，点人进入个人主页。（示例数字来自演示数据）

## 动态

顶部筛选：全部 / 和我有关 / 我的团队（有团队的人才有）/ 需要支持 / 新目标。新动态从顶部滑入并短暂发暖光。每条是一句人话，例如“周以宁 给 抖音店播 记了 +12 万元”，下面一行“累计 82 / 120，完成 68%”，带目标路径和说明原文，可以点赞和回复（示例为虚构）。

## 弹层表单

桌面居中，手机从底部升起。所有表单都是单列，必填项尽量少：

- **记一笔**：“这次新增多少？”（大输入框；“做完就行”的目标改为勾选完成）、“一句话说说（可选）”、“感觉怎么样？（可不选）”三选一：顺利 / 有点担心 / 需要支持（选“需要支持”时上级和协作者会在动态里第一时间看到）；日期默认今天，补记以前的才需要展开修改。没有记数字权限的人看到的是“说一句”留言框。
- **新建目标**：标题 → “有一个数字 / 做完就行” → 目标值和单位（拆在同单位上层下面时提示“记在这里的数字会自动汇总到「上层」”）→ 负责人和协作者 → 周期（默认继承上层）。
- **拆给成员**：选多个人，逐人填份额，实时显示合计和剩余；全部拆完再拆会提示“相当于给团队留了冲刺空间”。

出错时表单轻晃一下，并在字段下方写明原因和改法。

## 设置（仅公司负责人）

五个页签：成员（搜索、按部门 / 已离职 / 未配置登录筛选，编辑、离职、交接）、组织（部门和负责人）、规则（谁能看到什么、多久没更新算“很久”、节奏判断的两条线）、已归档（可恢复）、数据（下载备份、升级迁移说明）。

## 50–80 人时依然简单的做法

1. 每个人默认只看到和自己相关的内容：一线成员首屏通常只有几个目标。
2. 首页卡片按需要关注的程度排序，最需要看的在最前面；列表超过一定数量折叠“看全部”。
3. 目标地图只放公司目标，不把整棵树铺开；下探一层看一层。
4. 头像叠放最多 4 个，其余显示“+N”。
5. 新人有一次性引导，空状态都给下一步按钮。

原 v0.3 交付时用 63 人的演示数据和补到 80 人的测试数据检查过：各身份首屏数据量和耗时见《11 交付验收结果》，页面效果见 `docs/screenshots/`。
