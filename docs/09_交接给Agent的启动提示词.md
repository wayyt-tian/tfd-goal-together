# 交接给研发助手的启动提示词

请维护这个轻松协同的目标共创台，保留现有页面功能和布局。先读根目录 `AGENTS.md` 及 `docs/00_先读我.md`、`02_业务规则与权限.md`、`07_已知问题与迭代路线.md`。

源码已整理到根目录的 `src/`、`web/`、`scripts/`、`tests/`。技术栈为 React 19 + Vite 7、Node.js JavaScript、PostgreSQL 16，依赖通过 `npm ci` 安装。当前不提供 SQLite 数据迁移。

本地配置在私有 `.env`。使用 `npm run db:setup` 创建项目专用数据库容器；`npm test`、`npm run demo` 和 `npm run test:browser` 只使用专用测试/演示库和临时空间。不要连接真实工作库，不要按进程名批量结束 Node。

服务端权限、增量流水、归档恢复、版本冲突、提交后广播均不可退化。界面、文档和提示用简体中文。修改后同步文档并完成适当回归；性能优化以可检查的架构改动和正确性测试为依据，不宣称未测量的生产并发能力。
