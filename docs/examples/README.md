# 数据与接口样本

| 文件 | 内容 |
| --- | --- |
| `schema.sql` | v0.3 全部 12 张表和 8 个索引，带中文字段说明。只供阅读，启动 `src/server.cjs` 会自动建表。 |
| `api-examples.json` | 24 个接口调用示例：在临时数据目录里用虚构人员真实调用一遍生成，包括初始化、登录、新建目标、拆解、记进展、自主目标、编辑冲突、撤回、详情、增量、动态、点赞、规则、离职与一键交接，以及常见的 403 和 409。长列表只保留前两项。 |

不要把这里的 SQL 或 JSON 直接写进正式数据库。

想要一套能点开体验的数据，用演示模式（全部虚构，63 人，4 个演示身份）：在项目根目录运行 `npm run demo`；想看到动态不断冒出来，运行 `npm run demo:live`。演示用的是独立的临时数据目录，关掉就清理，不会碰正式数据。80 人规模的验证在 `npm test` 的「80 人规模」一组里自动完成。

v0.2 的 `scale-fixture-80.json` 已删除：它描述的是旧的 JSON 业务结构，对 v0.3 没有参考价值。
