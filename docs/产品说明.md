# 锅气家族 · 目标共创台：产品说明

完整的验收约定在同目录《01 产品与验收》，权限与计算规则在《02 业务规则与权限》。本文只讲产品为什么这样设计。

## 要解决的问题

公司有两条核心经营线：GMV 和浪花收入（工具与管理咨询对外合作创造的收入）。管理者需要随时知道：公司目标拆到了哪些业务、哪些人；每个人做到了哪里；按时间进度哪里慢了；最近有什么新变化。同时，同事填报要几乎没有成本，也不该有被考核的压力。50–80 人时，第一次用的人也要一眼看懂。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 目标 | 唯一的核心对象。有标题、负责人、协作者、周期，分“有一个数字”和“做完就行”两类 |
| 公司目标 | 公司负责人建的根目标（北极星），例如“12 月 GMV 1000 万元” |
| 拆解 | 任何人都可以在自己负责或参与的目标下继续拆：拆给成员（带份额）或拆关键动作。深度不限 |
| 自主目标 | 任何人自己发起的目标，可以挂靠到看得见的组织目标表明方向。不计入公司汇总 |
| 记一笔 | 进展记录：只填这次新增的数字，一句话说明可写可不写；可以标“需要支持” |
| 动态 | 每一次新建、拆解、记一笔、达成、留言、点赞都变成一句人话，实时推给看得见的人 |
| 汇报线 | 每人一个直属上级。上级看得到下属及下属的下属的目标 |

## 四个页面，各回答一个问题

| 页面 | 问题 | 怎么回答 |
| --- | --- | --- |
| 我的 | 我要推进什么？ | 问候区一句话总结 + “刚刚”滚动快讯；我负责的 / 我参与的 / 我的自主目标三组卡片，每张卡片顶上写着它属于哪个公司目标；离开期间的变化汇总；有团队的人多一块团队速览和锅气小助手 |
| 目标地图 | 公司目标拆到了哪里？ | 最上层只放公司目标，点进目标页逐层下探；“现在最需要关注”列出落后、需要支持或很久没更新的末端目标；大家发起的自主目标可展开 |
| 团队 | 我的人怎么样？ | 下属按“需要关注的程度”排序：谁顺利、谁需要支持、谁很久没更新，点进去看个人 |
| 动态 | 刚刚发生了什么？ | 实时动态流，可按 全部 / 和我有关 / 我的团队 / 需要支持 / 新目标 筛选，点赞和回复在原地完成 |

目标页把一个目标讲清楚：是什么、谁负责、谁协作、做到哪了、节奏如何，下面三个页签：拆解路径（下一层由哪些路径组成）、成员（每个人的份额和状态）、动态（这个目标的全部变化）。

## 设计取舍

1. **不做考核**：不打分、不排名、不审批。状态只有 顺利 / 稍慢 / 落后 / 已达成 / 未开始 / 未定数字，按时间进度判断；目标刚开始的 3 天不标慢。
2. **填报极简**：一个数字 + 可选的一句话。不要求每周固定填，有进展就记。
3. **共创而不是派单**：任何人看到高价值的机会都能直接新建目标或关键动作，挂到相关的目标下，上级和全公司实时看得到。
4. **可见即相关**：默认每个人只看到和自己、自己团队有关的路径及其上层方向，避免 80 人的信息淹没新人；公司负责人可以改为公司目标全员公开。
5. **有呼吸感**：实时推送 + 动效 + IP 形象，让系统看起来“在动”，但不催人。
