# 测试与回归

开发前的 SQLite 基线为 5 组 54 个用例。本轮改用专用 PostgreSQL 测试库中的随机隔离空间，正常退出自动删除；双模式测试的演示实例另用专用演示库的随机空间，不连接正式库。当前命令：

```sh
npm test                  # 构建 + 7 组后端回归
npm run test:browser       # React 浏览器交互
npm run demo:check         # 4 个演示身份
npm run test:smoke         # 非演示首次启动、静态资源、源码边界及演示启动
npm run package:manifest
npm run package:check
```

后端覆盖目标主流程 22 项、安全与静态资源 7 项、80 人顺序功能样本 5 项、PostgreSQL 初始化/事务/恢复/并发正确性及重启 8 项、通讯录导入 8 项，共 50 项。旧 SQLite 升级测试已由 PostgreSQL 专属测试替代，不表示 SQLite 数据已迁移。

数据库检查包括初始化幂等、真实备份恢复、失败事务撤回、提交游标次序、独立空间隔离、并发版本冲突和重复流水去重。并发用例用于验证正确性，不构成负载或吞吐测试。80 人样本只检查权限和数据范围，耗时仅供排查，不设置机器相关的速度通过线。

React 浏览器检查覆盖身份选择、导航、新建目标、类型切换、日期切换、嵌套选人、特殊字符、记进展、留言、撤回恢复、编辑、协作者、归档恢复、首次设置与日常登录、实时更新时保留草稿与焦点、搜索、手机导航和横向溢出。

`tests/browser/capture.cjs` 在 1366、1440、390 三种宽度、4 个身份下采集 135 个页面/弹层状态，另有登录页截图。固定业务日期和浏览器时钟，复核截图时同时固定服务端时钟。旧版截图存放在本次开发机临时目录，不作为发布依赖。自动截图覆盖代表页面，不替代读屏软件、真实触屏设备及所有边界交互的人工验收。

交付清单只包含源码、锁文件、配置模板、素材和文档；忽略本地依赖、构建结果、私有 `.env` 和运行产物。交付文件中仍禁止混入数据库、备份、真实通讯录和符号链接。

v0.4 增加 `test-formal` 12 项和 `test-operations` 5 项，正式浏览器流程 8 项；原有领域样本通过测试夹具转换为新密码开通流程，产品接口不支持旧后四位登录。新版契约测试使用 `legacyFixtures:false`，直接验证缺少凭证、缺少版本、重放链接和越权均被拒绝。恢复验收只创建随机新测试库并在结束后删除。完整边界见 [正式模式与账号管理](14_正式模式与账号管理.md)。
