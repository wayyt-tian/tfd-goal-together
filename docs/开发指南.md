# 开发指南

从项目根目录执行命令。当前技术栈为 React 19 + Vite 7、Node.js JavaScript、PostgreSQL 16。

先阅读 [AGENTS.md](../AGENTS.md)、[业务规则](02_业务规则与权限.md) 和 [已知问题](07_已知问题与迭代路线.md)。安装、连接配置、前后端开发及容器部署见 [本地开发与部署](05_本地开发与数据续接.md)，代码职责见 [架构与代码地图](03_架构与代码地图.md)，回归命令见 [测试与回归](06_测试与回归.md)。

修改前后运行 `npm test`。验证仅使用专用演示库和测试库。前端视图直接返回 JSX，公共控件和局部刷新由 React 协调，禁止重新引入运行时 HTML 模板解析。样式和功能布局需保持现有基线；新增功能优先放入已有页面。

所有写操作必须在请求事务内完成并写事件，响应和实时通知只能在提交后发送。进展流水不可物理删除，目标删除走归档。权限必须在服务端验证，目标编辑必须携带版本号。
