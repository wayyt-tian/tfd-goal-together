## 已完成

- 目录整理为 `src/`、`web/`、`assets/`、`scripts/`、`tests/`、`tools/`、`infra/` 和 `docs/`，根目录统一命令、配置和锁文件。

## 性能与正确性

服务端使用连接池和异步查询；批量读取组织信息，避免逐成员查询。对有效进展、最近自评、动态、会话、负责人和归档增加索引。读模型按提交游标与日期复用，普通进展只更新受影响目标及祖先的汇总，结构变化完整重建。动态在 SQL 中授权过滤并分页，凭据派生改为异步。

事件、目标变化和游标在一个事务中提交；失败事务不发布缓存。事务游标行保证提交次序，写入批次仍串行，读请求可并行。响应、动态通知和点赞广播都延后到提交成功。版本冲突继续返回 409，重复流水编号去重，历史流水不物理删除。

React 页面按需分包，在线人数变化只更新顶栏；增量合并只更新受影响的父子索引。静态资源使用内容指纹、长期缓存、ETag、压缩缓存；入口重新校验，服务器推送保持独立。

这些是架构改动和功能验证，未进行负载或压力测试，也不提供生产吞吐保证。多实例统一限流和登录锁定仍未实现，正式运行建议单应用进程。
