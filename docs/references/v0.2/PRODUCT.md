# 锅气家族 · 绩效工作台

工作台提供两条查看路径：公司指标 → 组织业务目标 → 成员份额 → 反馈记录，以及一级组织 → 二级组织 → 成员 → 本人全部目标。目标的归属直接引用组织架构，可单选或多选一级、二级组织；选择一级包含全部下级。多组织共用一条目标和目标值，公司汇总只计一次，成员各自按负责份额反馈。

新增和编辑目标使用现有两级组织树，不再新建独立业务小组。旧目标保留原分组供查看，编辑时需明确选择实际归属组织。归属组织用于描述目标，管理者的数据查看范围仍按其负责组织内的成员计算，不因跨组织目标而扩大权限。

公司负责人管理两级组织、用户和公司目标；部门负责人查看其所负责部门的所有成员、目标和反馈，可给范围内成员设置其他目标；成员查看自己的全部目标，可为自己增加其他目标。所有人只能更新本人的完成进展。

公司指标和成员其他目标独立计量。每条业务反馈只记入一份成员目标。成员其他目标记录归属人、名称、量化值、单位、说明和月份，不计入公司业务额，不同单位不相加。

每次反馈提交新增值，保留流水并累计有效值；负数冲减要求说明原因，累计不能为负。支持当前月撤销与恢复，保留原始反馈。负责人可逐人、逐目标查看更新日期、数值和说明。

公司负责人可删除当前月业务目标或移除已关联责任人，包括已有反馈的关联；个人其他目标由本人、范围内负责人或公司负责人删除。目标、关联及原始反馈一并移入「已删除」，从当前汇总中移除并释放额度，可查看和恢复。恢复检查所属目标、重复关联、剩余额度、组织范围及版本；历史月份只读。部门仍被有效或已删除目标引用时，需先调整目标归属后再删除。

权限由服务端按当前组织计算：公司负责人覆盖全公司；一级负责人继承全部二级部门；同一负责人可负责多个部门，合并去重。负责人自己的目标在个人入口可见，即使隶属其他部门，也不计入所负责组织汇总。删除用户撤销登录，取消负责人任命，保留业务历史，可恢复。非空部门先调整人员或下级，至少保留一位公司负责人。

账号配置和登录采用手机号、姓名、身份证后四位，后四位加盐哈希且不回显。Node 与 SQLite 保存会话和业务数据，版本号检测并发修改。演示为 2026 年 12 月、12 月 20 日截点，历史只读。角色化演示业绩不代表真实同事绩效，附件仅作为参考。

绩效详情使用可展开的结果目标树：指标总目标 → 结果目标 → 成员责任份额 → 有效反馈依据。各层完成值由下层有效结果相加，完成度以本层目标值为分母，不平均子项完成率。未拆解、未分配份额明确展示。当前范围按用户确认仅包含结果目标及责任人份额。树搜索和进展筛选只影响展示，不改变上方总数；多组织目标计一次。

50–80 人使用时，先看概况，再查看单人明细。目标与人员名单分页，树成员和流水分批展开；手机组织范围可收起，组织指标汇总按需展开。当前周从截止日所在周一开始，有效成员的正数份额才产生待反馈提示。常规保存只上传变化记录，服务端复核当前组织范围和并发版本。具体限制及验证见设计审查报告。
