# 设计与品牌规范

完整的设计说明见 [设计说明](设计说明.md)，品牌素材的来源和处理见 `assets/brand/README.md`，界面截图见 `docs/screenshots/`。v0.2 的设计规范和审查报告存档在 `docs/references/v0.2/`，仅供对照，以本文件为准。

## 一、气质：轻松、协同、有呼吸感

这是一张“大家一起往前推”的工作台，不是考核表。所有设计决定都围绕三件事：

1. **没有压力感**：不打分、不排名；状态用“顺利 / 稍慢 / 落后”这类口语，不用“不合格”“预警”；很久没更新只提醒“N 天没更新”，不扣分；IP 形象只出现在问候、引导、空状态、庆祝和点赞，从不出现在“落后”旁边。
2. **看得见在动**：顶栏呼吸灯表示实时连接；别人刚记的进展从上方滑入并短暂发光；数字更新后环形进度平滑过渡；达成时有庆祝动效和喜报。
3. **一次只回答一个问题**：“我的”回答“我要推进什么”；“目标地图”回答“公司目标拆到了哪里”；“团队”回答“我的人怎么样”；“动态”回答“刚刚发生了什么”。信息按需展开，80 人的组织也不会一屏铺满。

## 二、设计变量（`web/css/app.css` 开头）

| 用途 | 变量 | 值 |
| --- | --- | --- |
| 品牌暖橙（主按钮、选中态） | `--brand` | `#FF6A2E` |

| 暖金（光晕、喜报） | `--gold` | `#FFC34D` |
| 深灰（标题、Logo 字色） | `--slate` | `#3D4652` |
| 页面底色（暖白） | `--bg` | `#FFF8F1` |
| 顺利 / 已达成 | `--ok` | `#22A06B` |
| 稍慢 | `--watch` | `#E3A008` |
| 落后 | `--risk` | `#E5484D` |
| 需要支持 | `--help` | `#7C5CFC` |
| 圆角 | `--radius` / `--radius-sm` | 18px / 12px |
| 缓动曲线 | `--ease` | `cubic-bezier(.22, 1, .36, 1)` |
| 字体 | `--font` | DM Sans（本地，数字和拉丁字母）→ PingFang SC → Hiragino Sans GB → Microsoft YaHei |

品牌四色取自用户提供的品牌规范图。数字统一用等宽数字（`tabular-nums`），数字和单位分层：数字大、单位小。

状态永远“颜色 + 文字”同时出现，不只靠颜色：

| 状态 | 文字 | 颜色 |
| --- | --- | --- |
| ok | 顺利 | 绿 |
| watch | 稍慢 | 黄 |
| risk | 落后 | 红 |
| done | 已达成 | 绿 |
| upcoming | 未开始 | 灰 |
| neutral | 未定数字 | 灰 |
| 需要支持 | 单独的紫色标签 | 紫，不改变上面的状态 |

## 三、动效

| 名称 | 用在哪里 | 作用 |
| --- | --- | --- |
| `breathe` | 顶栏实时连接点（绿） | 系统在“呼吸”，有新动态会自动出现 |
| `blink` | 连接点（黄 / 灰） | 正在重新连接 / 连接中 |
| `breathe-brand` | 未读的新动态小圆点 | 有你还没看过的变化 |
| `breathe-scale` | 启动加载时的品牌标志 | 加载中 |
| `float` | 首页、登录页、引导卡、空状态里的 IP 形象 | 轻微上下漂浮，让页面不呆板 |
| `slide-down` + `glow` | 新到的动态条目、首页滚动快讯 | 从上方滑入并短暂发暖光，提示“刚刚发生” |
| `page-in` | 切换页面 | 6 像素上移淡入 |
| `sheet-in` / `sheet-up` | 弹层（桌面居中 / 手机从底部升起） | 表单出现 |
| `pop` | 点赞按钮 | 点一下弹一下 |
| `celebrate-pop` + `confetti` | 目标达成 | IP“加油”动作 + 彩纸 |
| `shake` | 表单出错 | 轻微左右晃动，配合文字说明 |

系统开启“减少动态效果”时，所有动画和过渡缩短到几乎为零，连接点改为静态光圈。

## 四、版式与响应式

| 宽度 | 布局 |
| --- | --- |
| 1080px 以上 | 顶栏导航 + 内容区，首页公司目标卡片多列 |
| 760–1080px | 栅格收窄 |
| 760px 以下（手机） | 顶栏只留 Logo、呼吸灯和头像；底部导航栏（我的 / 目标地图 / 团队 / 动态）；右下角圆形“+”新建按钮；卡片单列；弹层从底部升起 |
| 380px 以下 | 进一步压缩间距和字号 |

底部导航和“+”按钮避开 iPhone 底部安全区。宽内容在容器内横向滚动，整页不允许横向溢出（每次截图走查都会检查）。

## 五、品牌与 IP 使用

| 文件 | 用在哪里 |
| --- | --- |
| `guoqi-logo.webp` / `guoqi-logo-sm.webp` | 登录页 / 顶栏 |
| `guoqi-mark.png` | 浏览器标签图标、启动加载 |
| `ip-full.webp` | 登录页、首次引导 |
| `ip-happy.webp` | 首页问候区、演示身份选择 |
| `ip-think.webp` | 锅气小助手、空状态、出错页 |
| `ip-cheer.webp` | 目标达成庆祝 |
| `ip-thumbs.webp` | 有人给你点赞的轻提示 |

规则：

1. 页面里的 IP 一律不带“加油！”字样（原始矢量图在 `source/` 里，只供设计追溯，服务端不对外提供）。
2. IP 不当任何人的头像，也不用来表示“落后”“稍慢”等业绩状态。头像统一是文字头像：中文名取最后两个字（最小号和叠放时取一个字），英文名取前两个字母，配按人固定的底色。
3. 图片保持原比例，不拉伸、不改色；只做了裁切、去底、压缩，没有重画角色或标志。
4. 品牌素材的授权以用户为准，与 Lucide 图标（`assets/licenses/LICENSE-lucide.txt`）和 DM Sans 字体（`assets/fonts/OFL-DM-Sans.txt`）的开源许可证无关。

## 六、文案语气

像同事之间说话：“记一笔”“拆给成员”“需要支持”“TA 名下还有 3 个目标没人接手”。不用“考核”“排名”“扣分”“不达标”；标题里不用 OKR、KPI 之类的英文缩写（GMV 可以）。提示要说清楚下一步怎么做，比如“这个目标刚刚被更新过，已为你载入最新内容，请再确认一次”。

## 七、可访问性

所有操作都能用 Tab / Enter 完成；Esc 关闭弹层并把焦点还给打开它的按钮；按钮都有可读名称，选择类按钮带 `aria-pressed`；表单错误有文字说明。已做基础检查，但没有用读屏软件和真实触屏设备完整审核，不要对外声称完全符合无障碍标准。
